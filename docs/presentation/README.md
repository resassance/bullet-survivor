# Освещение и сюжетные сцены

Ветка продолжает `feat/story-final-boss`. В `main` изменения не отправляются.

## Свет

- Лагерь: холодный свет неба, тёплый костёр с плавным мерцанием и тенями, слабый фонарь у ворот. Корпуса станций больше не светятся целиком.
- КПП: холодный рассеянный свет, два неподвижных прожектора, янтарные огни у баррикады, туман и потёртая разметка полосы боя.
- Персонажи и будущие плоские ассеты реагируют на освещение. Небольшая собственная подсветка сохраняет читаемость силуэтов.
- HDR → bloom только от ярких источников → ACES → лёгкое снижение насыщенности и виньетка. Случайный глитч удалён.
- В каждой сцене только один источник отбрасывает динамические тени: костёр (кубическая карта 512) или ближний прожектор (1024).

Палитра и силы света: `src/world/lightingProfiles.ts`. Положение костра берётся из `CAMP_LAYOUT`; свет следует за ним при изменении планировки.

## Новелла

Все диалоги используют общую сцену: схематичный фон, контурные фигуры Юки и Рэна, выделение говорящего, название сцены, локация, счётчик реплик и отдельные кнопки продолжения и пропуска.

Управление: нажатие на сцену, Enter, пробел или стрелка вправо. Tab переключает кнопки внутри сцены; скрытые новелла и титры не принимают фокус. Системная настройка уменьшения движения отключает анимации.

Рисунки не загружаются по умолчанию. Чтобы заменить заглушки, задайте необязательное `imagePath` у персонажа или фона в `src/gameplay/novelScenes.ts`. Заглушка исчезает после успешной загрузки; ошибки загрузки не прерывают сцену. У новых реплик доступны поля `title`, `chapter`, `continueLabel`.

## Финал 10-го этапа

1. Четыре отражения разрушают укрытия.
2. Игрок выбирает центр; оба героя доходят до него.
3. Открывается отдельный эпилог «Возвращаемся домой» (6 реплик).
4. Последняя кнопка «К титрам» или пропуск сцены сохраняет завершение истории и через затемнение открывает титры.
5. «Вернуться в лагерь» возвращает в лагерь и открывает существующий доступ к бесконечному режиму.

Для ручной проверки можно выбрать 10-й этап через DEBUG (9 раз «вперёд»), выйти из лагеря в бой и использовать «пропустить» для перехода к появлению Рэна. Вторую фазу нужно пройти: Юки выбирает угол, противоположный цели босса. После четвёртого отражения выбрать центр.

## Проверки

`npm test`, `npm run build` и `git diff --check` проходят. Тесты покрывают модель финального боя, включая четыре укрытия и достижение центра.

Дополнительно изолированно проверены реальные методы `Game` с подставленными UI-компонентами: эпилог открывается до сохранения финала; титры появляются только после завершения новеллы и в середине затемнения; кнопка титров возвращает в лагерь. Это проверка порядка вызовов, а не браузерного интерфейса.

Скриншоты и браузерное прохождение в этой среде не выполнены: локальный сервер получает `listen EPERM`, Chromium не запускается из-за ограничения `setsockopt`. Требуется визуально проверить яркость, тени, длинные реплики и титры на desktop, узком телефоне и телефоне в альбомной ориентации. Производительность на реальном телефоне не измерена.
