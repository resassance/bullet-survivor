# Лагерь: схематичная сцена под будущие 2D-ассеты

Лагерь показан простыми геометрическими формами без иллюстраций и текстур. Ворота находятся в глубине, костёр и два схематичных персонажа — впереди, шесть станций — по сторонам. Подписи и кнопки остаются отдельным интерфейсом.

## Расположение

- `src/gameplay/campStations.ts`: позиции станций, размеры рамок будущих изображений и высота подписи.
- `src/gameplay/campLayout.ts`: костёр, пламя, персонажи, флаг, ящики, задник и настройки земли.
- `src/utils/constants.ts`: общий ракурс камеры и свет.

Размеры `width` и `height` задают рамку в мировых единицах. Схематичная геометрия вписывается в эту рамку с сохранением пропорций. По умолчанию точка опоры — нижний центр. `propPosition` относится к этой точке; `labelHeight` отдельно задаёт высоту подписи.

В лагере нет подключённых иллюстраций. Пока `path` не задан, загрузчик не делает запросов изображений. Чтобы добавить свой 2D-ассет, положите файл в `public/assets/camp/` и задайте путь в нужном определении:

```ts
asset: {
  path: '/assets/camp/gate.png',
  width: 7.2,
  height: 6.55,
  pivot: [0.5, 0],
}
```

Загрузчик покажет рисунок после успешной загрузки и скроет временную геометрию. Если загрузка не удалась, схема останется доступной. Рисунок вписывается без растягивания. `pivot` задаётся от 0 до 1 с отсчётом от левого нижнего угла; `[0.5, 0]` — нижний центр. Убирайте лишние прозрачные поля снизу, чтобы предмет стоял на земле.

Текстуру земли можно подключить через `CAMP_GROUND.texturePath`. По умолчанию земля однотонная. Юки и Рен используют отдельные определения `character` и `companion`; костёр разделён на основание, пламя, свет и искры.

## Композиция и взаимодействие

Камера сохраняет почти фронтальный ракурс и лишь немного приближается при выборе станции. На узком экране она показывает лагерь целиком, а кнопки переходят в компактную сетку.

Станции используют HTML-кнопки и иконки Phosphor. Работают мышь, касание и клавиатура. Нажатие закрытой станции объясняет условия открытия. Скрытые панели и кнопки исключаются из взаимодействия через `inert`.

Существующая игровая логика сохраняется: оружие, архив, настройки, спецоружие, история и бесконечный режим. После возврата из паузы активная точка запуска показывает «ПРОДОЛЖИТЬ БОЙ».

## Проверка

`npm ci` и `npm run build`.

Проверьте настройки звука, условия открытия, архив и возврат, клавиатуру, запуск истории и маршрут «бой → лагерь → продолжить бой». Повторите на широком и узком экране: все шесть станций должны быть доступны без перекрытия подписей.

Актуальные скриншоты: [широкий экран](desktop.webp), [узкий экран](mobile.webp).
