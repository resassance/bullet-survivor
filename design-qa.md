# Проверка схематичного лагеря

Текущая цель: простые геометрические формы без сгенерированных иллюстраций и текстур, с сохранением расположения и работающих станций.

## Визуальные материалы

- Широкий экран: `docs/camp/desktop.webp`, 1536 × 864 CSS/pixels.
- Узкий экран: `docs/camp/mobile.webp`, 390 × 844 CSS/pixels.
- deviceScaleFactor: 1, состояние — лагерь перед первым этапом.
- Снимки получены из работающего приложения в локальном Chromium через Playwright. Облачное превью не публиковалось.

Сгенерированные ассеты, исходный эскиз и старые сравнения удалены из актуальной версии ветки. Скриншоты документации показывают схематичную сцену.

## Результат

Станции представлены простыми формами; ворота, костёр, флаг, ящики и два персонажа читаются как отдельные объекты. Все шесть подписей находятся внутри широкого экрана и не перекрываются. На узком экране кнопки переходят в компактную сетку; минимальная высота области нажатия — 44 px.

Пути изображений не заданы, поэтому лагерь не запрашивает удалённые ассеты. Текстура земли также отключена. Сохранена возможность подключить свои 2D-изображения: размеры рамок, нижние точки опоры и сохранение пропорций используют один контракт для схемы и будущего рисунка.

## Проверки

В браузере проверены настройки звука, объяснение открытия закрытой станции, архив и возврат, клавиатурная активация, все кнопки узкого экрана, запуск истории, отключение скрытых элементов, пауза → лагерь → продолжение боя. Исключений JavaScript нет; неудачных запросов ассетов лагеря нет.

`npm run build` и `git diff --check` проходят. Vite сохраняет предупреждение о размере JavaScript-бандла. В dev-консоли отмечены два сообщения о загрузке ресурсов, поэтому отчёт не заявляет полностью чистую консоль.

final result: passed
